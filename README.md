# Grok Bot

Bot điều phối (bố) cho các Trợ Lý Edit Video số 1–5.

## Vai trò
- Nhận job từ chủ
- Chia việc, đánh số bot con, gửi qua SendToAgent
- Gom kết quả và báo lại chủ (tiếng Việt)

## Nội dung gói
- `profile.json` — tên và mô tả bot
- `memory.md` — bộ nhớ đã học
- `instructions.md` — quy ước điều phối
- Không có token, mật khẩu, hay media nặng
